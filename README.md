# FIRST-PROTFOLIO

Personal portfolio website for **Pawani Sharma** — full-stack developer, Microsoft Azure certified, B.Tech CS student at SRM University.

## Live Demo

Deploy on [Vercel](https://vercel.com) for a live URL like `first-protfolio.vercel.app`.

## Sections

- Hero with profile & resume download
- About & languages
- Technical skills
- Projects with GitHub links
- Education timeline
- Microsoft certifications
- Contact & social links

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
